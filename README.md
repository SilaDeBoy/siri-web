# Siri-style Voice Web App

A lightweight voice assistant UI inspired by Siri. Runs entirely in the browser.

## Features

- Glowing orb + listening waveform
- Speech recognition (Chrome / Edge recommended)
- Spoken replies
- Commands such as:
  - “Open YouTube”
  - “Search YouTube for music”
  - “Open Instagram”
  - “What time is it?”
- Suggestion chips for one-tap actions
- Opens sites in a **normal new browser tab** (user-initiated)

## Important

This app does **not** auto-watch videos, farm views, or control your phone’s apps in the background.  
It only opens public web links the same way a normal link would.

## How to run

1. Open `index.html` in Chrome or Edge (best mic support).
2. Allow microphone access when prompted.
3. Tap the mic (or the orb) and speak.

### On a phone

- Use Chrome / Safari
- Add to Home Screen for a fuller-screen feel
- Mic permission is required for voice
